# 二维码结果屏幕显示操作指南

> 若要完整启动“摄像头 → 二维码识别 → 7 寸屏显示”，优先看合并版：`src/二维码识别与屏幕显示操作指南.md`。本文只保留屏幕显示节点的单独说明。

> 适用节点：`qr_result_display`  
> 作用：订阅 `/sign_foxglove` 和 `/qr_code/data`，根据顺/逆时针结果读取 txt 文件，并在 7 寸 HDMI 屏全屏显示方向和二维码原始数据。

## 1. 当前显示逻辑

| 输入信号 | 含义 | 读取文件 | 屏幕显示 |
|---|---|---|---|
| `/sign_foxglove = 3` | 顺时针 ClockWise | `clockwise.txt` | 顺时针提示 |
| `/sign_foxglove = 4` | 逆时针 AntiClockWise | `anticlockwise.txt` | 逆时针提示 |
| `/qr_code/data = xxxx` | 二维码原始内容 | 不读取文件 | 追加显示原始数据 |
| 未收到结果 | 等待二维码 | `waiting.txt` | 等待提示 |

当前二维码规则：

```text
1~9999 奇数 -> qrcode_detector 发布 3 和原始数据 -> 屏幕显示顺时针文本 + 原始数据
1~9999 偶数 -> qrcode_detector 发布 4 和原始数据 -> 屏幕显示逆时针文本 + 原始数据
```

## 3. 启动前确认

7 寸屏已经能显示 Linux 桌面，所以使用 Python 自带的 `tkinter` 全屏窗口显示。

需要确认：

```bash
python3 -c "import tkinter; print('tkinter OK')"
```

如果失败，需要安装：

```bash
sudo apt install -y python3-tk
```

## 5. 单独测试屏幕节点

### 5.1 X11 图形授权说明

如果在 7 寸屏本机桌面终端启动，通常不需要额外授权。

如果从 MobaXterm 的 SSH 终端启动屏幕窗口，需要先让本机 X server 允许
`root` 使用当前桌面显示。请在 7 寸屏本机桌面终端执行：

```bash
xhost +SI:localuser:root
```

这条命令通常只需要每次图形桌面会话执行一次：

```text
同一次桌面登录期间：一般只执行一次即可
重启小车后：需要重新执行
注销/重进桌面后：需要重新执行
X server 重启后：需要重新执行
```

说明：

- `xhost +SI:localuser:root` 只授权本机 root 用户，比 `xhost +` 安全。
- 如果从 7 寸屏本机终端直接运行 `qr_result_display`，一般不需要这条命令。
- 如果希望以后开机后自动允许 SSH root 启动屏幕窗口，可以把这条命令放入桌面用户的自启动脚本；当前调试阶段建议先手动执行。

### 终端 1：启动屏幕显示节点

> 📋 **贴到 MobaXterm 执行**：

```bash
source /opt/tros/humble/setup.bash
source /userdata/dev_ws/install/setup.bash
export ROS_DOMAIN_ID=30
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export DISPLAY=:0

ros2 run dg_pkg qr_result_display
```

屏幕应显示等待二维码的提示。

### 终端 2：手动发布顺时针

> 📋 **贴到 MobaXterm 执行**：

```bash
source ~/.bashrc
ros2 topic pub --once /sign_foxglove std_msgs/msg/Int32 "{data: 3}"
```

期望：屏幕显示 `clockwise.txt` 内容。

### 终端 3：手动发布逆时针

> 📋 **贴到 MobaXterm 执行**：

```bash
source ~/.bashrc
ros2 topic pub --once /sign_foxglove std_msgs/msg/Int32 "{data: 4}"
```

期望：屏幕显示 `anticlockwise.txt` 内容。

## 6. 联合二维码识别测试

启动顺序：

1. 启动 USB 摄像头。
2. 启动 `qrcode_detector`。
3. 启动 `qr_result_display`。
4. 扫奇数二维码，屏幕显示顺时针。
5. 扫偶数二维码，屏幕显示逆时针。

常用命令：

```bash
ros2 launch origincar_bringup usb_websocket_display.launch.py
ros2 run dg_pkg qrcode_detector --ros-args -p debounce_frames:=2
ros2 run dg_pkg qr_result_display
```

如果要同时观察信号和原始数据：

```bash
ros2 topic echo /sign_foxglove
```

另一个终端：

```bash
ros2 topic echo /qr_code/data
```

## 7. 修改显示文字

只需要改 txt 文件，不需要改 Python 代码。

例如修改：

```text
/userdata/dev_ws/src/dg_pkg/config/display_text/clockwise.txt
```

然后重新编译：

```bash
cd /userdata/dev_ws
source /opt/tros/humble/setup.bash
colcon build --packages-select dg_pkg --symlink-install
source install/setup.bash
```

如果只是临时测试，也可以直接改安装目录中的 txt：

```text
/userdata/dev_ws/install/dg_pkg/share/dg_pkg/config/display_text/clockwise.txt
```

但正式版本应改 `src` 目录并重新构建。

## 8. 退出屏幕显示

在屏幕窗口获得焦点时按：

```text
ESC
```

或者在启动终端按：

```text
Ctrl+C
```

## 9. 常见问题

### 9.1 终端显示 tkinter 找不到

执行：

```bash
python3 -c "import tkinter; print('tkinter OK')"
```

如果失败，安装：

```bash
sudo apt install -y python3-tk
```

### 9.2 MobaXterm 启动后小屏幕没弹窗口

确认命令是在小车本机桌面环境下启动，且 `DISPLAY` 存在：

```bash
echo $DISPLAY
```

如果为空，先在小车屏幕本机终端里启动，或设置：

```bash
export DISPLAY=:0
```

如果报错：

```text
Authorization required, but no authorization protocol specified
_tkinter.TclError: couldn't connect to display ":0"
```

说明 SSH 终端没有 X11 授权。请在 7 寸屏本机桌面终端执行：

```bash
xhost +SI:localuser:root
```

然后回到 MobaXterm 重新执行：

```bash
source ~/.bashrc
export DISPLAY=:0
ros2 run dg_pkg qr_result_display
```

### 9.3 中文显示成方块

说明系统缺少中文字体。可先安装中文字体：

```bash
sudo apt install -y fonts-wqy-zenhei fonts-wqy-microhei
```

然后重启 `qr_result_display`。
