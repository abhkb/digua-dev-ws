# 比赛规则与罚时记录

> 来源：用户在 2026-07-14 提供的当前比赛规则文本。  
> 用途：作为本项目导航、二维码、屏幕显示、通道巡航、返回 P 区停车策略的规则依据。  
> 注意：如组委会后续发布新版规则，以最新版官方文件为准，并同步更新本文。

## 1. 参赛人员及操作要求

1. 每支参赛队最多允许 5 名队员进入比赛场地。
2. 比赛开始前，须现场指定 1 名发车选手。
3. 比赛过程中，仅发车选手允许触碰车模。
4. 其他参赛选手可在场地周边协助录制比赛视频，但不得进入比赛场地或参与车模操作。
5. 比赛过程中，场内选手之间不得以任何形式交流与比赛操作有关的信息，包括但不限于：
   - 二维码内容；
   - 行驶方向；
   - 任务提示。
6. 违反上述交流限制的，每次罚时 20 秒。

## 2. 子任务一：P 区域出发、二维码识别与方向展示

### 2.1 完成要求

1. 发车后，车模须全程自主运行。
2. 不得使用上位机或其他外部设备进行遥控、干预或辅助操作。
3. 车模须自主识别二维码信息。
4. 车模须展示二维码数据解析后的：
   - 原始数字；
   - 顺时针或逆时针运行方向。
5. 上述展示要求在小车过半场后有效。
6. 完成上述要求，视为子任务一完成。

### 2.2 失败罚时

出现下列任一情况，视为子任务一失败，罚时 50 秒：

- 车模未实现全程自主运行；
- 使用上位机或其他外部设备干预车模运行；
- 未能识别二维码信息。

### 2.3 障碍物罚时

- 每碰撞障碍物一次，罚时 10 秒。
- 推动障碍物移动距离大于等于 1m，罚时 30 秒。
- 子任务一阶段障碍物罚时累计最高为 50 秒。

## 3. 子任务二：按二维码方向巡行 C 区黄色环形通道并完成人形立牌识别

### 3.1 开始条件

车模进入指定通道后，即视为子任务二开始。

### 3.2 路线与方向要求

1. 车模须根据二维码数据确定运行方向，并通过指定通道进入地图 C 区域。
2. 二维码方向规则：
   - 奇数：顺时针；
   - 偶数：逆时针。
3. 车模不得从黄色网格区域直接进入 C 区域。
4. 若误入黄色网格区域，可自主退出并重新通过指定通道进入 C 区域，不予罚时。
5. 车轮碾压黄色网格并进入其他任务，罚时 10 秒。
6. 进入 C 区域后，车模实际运行方向须符合二维码对应规则。
7. 若运行方向与二维码实际值不一致，视为子任务二失败，罚时 50 秒。

### 3.3 C 区限制

1. 进入 C 区域后，仅允许在黄色环形通道内行驶。
2. 不得驶入或碰撞浅绿色诊疗室区域。
3. 若非避障情况下：
   - 车轮碾压浅绿色诊疗室区域达到两个及以上；或
   - 车模驶入诊疗室区域；
   则视为子任务二失败，罚时 50 秒。

### 3.4 完成要求

子任务二完成须同时满足以下条件：

- 车模全程在规定的正确环形路线内运行；
- 车模按照二维码要求的方向运行；
- 车模最终从 B 区域通道驶出；
- 识别人形立牌、生成描述信息，并通过屏幕或语音展示。

未同时满足上述条件，视为子任务二失败，罚时 50 秒。

### 3.5 人形立牌与图生文展示要求

行驶过程中，车模须识别人形立牌，并通过大模型图生文生成对应的人形描述信息。

识别结果须通过以下任一方式展示：

- 车载屏幕显示；
- 语音播报；
- 车载屏幕显示与语音播报同时进行。

### 3.6 障碍物罚时

- 每碰撞障碍物一次，罚时 10 秒。
- 推动障碍物移动距离大于等于 1m，罚时 30 秒。
- 子任务二阶段障碍物罚时累计最高为 30 秒。

### 3.7 子任务二失败罚时累计规则

子任务二仅计算一次失败罚时。

同一子任务内出现多项失败情形时，失败罚时不重复累计，但障碍物罚时另行计算。

## 4. 子任务三：从 B 区域通道出口返回 P 区域并停车

### 4.1 开始条件

车模到达 B 区域通道出口后，即视为子任务三开始。

### 4.2 完成要求

子任务三完成须同时满足以下条件：

- 车模全程自主运行；
- 车模自主返回 P 区域；
- 车模自动停止；
- 停止后，车身至少二分之一位于 P 区域内，并保持静止。

未满足上述任一条件，视为子任务三失败，罚时 50 秒。

### 4.3 障碍物罚时

- 每碰撞障碍物一次，罚时 10 秒。
- 推动障碍物移动距离大于等于 1m，罚时 30 秒。
- 子任务三阶段障碍物罚时累计最高为 30 秒。

## 5. 比赛结束条件与计时

1. 车模须在 180 秒内从 P 区域出发，完成全部比赛任务并自主返回 P 区域。
2. 车模自动停止且车身至少二分之一静止位于 P 区域内时，视为比赛完赛。
3. 比赛计时：
   - 起点：裁判发出比赛开始指令；
   - 终点：车模满足完赛条件。

## 6. 对当前项目实现的约束

### 6.1 已满足或正在实现

- 二维码识别节点必须发布原始数字 `/qr_code/data`。
- 屏幕显示节点必须显示原始数字和顺/逆时针方向。
- 自动巡航不得依赖上位机遥控或人工发 goal。
- 返回 `p_return` 后必须自动停车。
- `p_return` 需要保证车身至少二分之一进入 P 区域，因此当前保留到点后前进 15cm 的补偿逻辑。

### 6.2 后续开发必须注意

- 调试阶段可以手动发布 `/sign_foxglove` 验收流程，但正式比赛必须由二维码节点自主识别。
- 正式比赛中不能由场内人员交流二维码内容、方向或任务提示。
- C 区巡行方向必须严格由二维码奇偶决定，不能手动选择。
- 子任务二必须同时完成通道巡行、方向正确、从 B 区驶出、人形立牌识别与图生文展示。
- 障碍物剐蹭会直接罚时；路径规划应优先留边，不应为了缩短距离贴障碍走。
- 推动障碍物超过 1m 是高罚时风险，应在局部避障和速度上保持保守。
